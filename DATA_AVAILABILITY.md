# Data Availability

## Source-image data

The source archive is publicly accessible from the Kaggle dataset **“DICOM data”** by
Ashraf Alsinglawi. The source JPEGs used by this study are not redistributed in this repository
because a dataset-level redistribution license was not independently verified from the accessible
metadata.

The exact 36 study image identifiers and SHA-256 hashes are provided in:

`supplementary/Supplementary_Table_S1_Image_Identity_Manifest.csv`

## Repository-provided materials

The Python reference code, frozen protocol and environment records, derived numerical results,
matched-selector detector outputs and split records, supplementary hash manifest, and analysis
materials are available in this repository:

https://github.com/dhok8400-png/Beyond-PSNR-Reproducibility-Artifact

The repository release is archived on Zenodo at:

**DOI: 10.5281/zenodo.23020088**

## Scientific scope

The experimental image files are JPEG derivatives and are not treated as verified original
acquisition DICOM objects. Archive labels do not establish patient independence or clinical status.
